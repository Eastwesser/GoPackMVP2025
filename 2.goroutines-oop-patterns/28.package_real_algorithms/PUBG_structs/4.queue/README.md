# Когда использовать очередь, а когда дек?

## Очередь (важна последовательность):

- Когда задачи должны обрабатываться строго в порядке их поступления.

Пример: 
Очередь сообщений, задач для бота, событий.

## Дек (важен приоритет):

- Когда нужно управлять приоритетами (например, срочные задачи добавляются в начало).

Пример: 
Управление задачами в игре, 
где срочные действия (например, "прятаться" или "лечиться") должны выполняться раньше обычных.
